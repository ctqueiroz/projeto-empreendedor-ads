# Orientações para Estudantes

## Primeiros Passos
1. Forme sua equipe (2 a 4 integrantes)
2. Defina um problema real para resolver
3. Crie um repositório no GitHub para o projeto
4. Preencha o template de escopo (`templates/escopo-projeto.md`)
5. Compartilhe o link do repositório com o orientador

## Durante o Projeto
- Faça commits frequentes (mínimo 1x por semana)
- Mantenha o README atualizado
- Documente decisões importantes
- Use branches para novas funcionalidades
- Teste antes de fazer merge

## Entrega Final
- README completo com instruções de instalação
- Apresentação de 10-15 minutos
- Demo funcional do sistema
- Código versionado e organizado
